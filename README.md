# 中文医学实体抽取

比较训练词典 D0、字符 BiLSTM＋GlobalPointer N0、中文 BERT＋GlobalPointer N1，以及零样本／三样本 API 抽取 L0/L3。程序返回九类实体、原文和 Unicode 右开字符区间，支持嵌套实体、方法对比、JSON 导出和固定权重 CPU 复现。

本项目用于非商业课程教学与研究。初始代码及示范制作由 AI 完成，界面姓名和教学责任映射不代表已发生的真人贡献、工时或签署。自动抽取结果需要核对，不用于临床诊断。

## 环境与独立资源

使用 Python 3.11 和 uv。依赖由 [pyproject.toml](pyproject.toml) 与 [uv.lock](uv.lock) 固定；Node.js 仅用于可选的前端离线检查。源码仓库为私有 `Harry6400/cmeee-ner-2026`，读取者需具备仓库访问权限。

数据和模型权重单独取得，不随 Git 分发。使用已收到且符合许可的正式资源包，先按 [教师资源清单](configs/teacher-assets.json) 或 [Windows 资产清单](configs/windows-assets.json) 核对文件名、大小和 SHA-256，再将资源包解压到源码根目录：

```text
项目根目录/
├── assets/CMeEE-V2.zip
├── models/trained/manifest.json
├── models/trained/N0-seed20261019.pt
├── models/trained/N1-seed20261019.pt
├── pyproject.toml
└── uv.lock
```

不要额外解压 `assets/CMeEE-V2.zip`，也不要在已收到合并资源包后重复叠加其他旧权重包。资源包中的模型卡、数据来源和许可说明应一并保留。资源获取地址以提供者实际给出的地址为准；仓库中的清单不是数据或权重本身，不能将空链接当作已发布资源。

原始数据由吴皓睿申请获批后从 [CBLUE 官方数据页](https://tianchi.aliyun.com/dataset/95414)取得，现有传递范围限本项目教师与组员的非商业课程复现。也可按官方渠道及适用条件自行取得数据；接收者应如实记录取得方式。详见 [数据许可](docs/DATA_LICENSE.md) 和 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 安装、检查与启动

在源码根目录执行：

```sh
uv sync --locked
uv run --locked python scripts/prepare_data.py --archive assets/CMeEE-V2.zip --output data
uv run --locked python scripts/prepare_data.py --output data --verify
uv run --locked python scripts/reproduce.py check
uv run --locked python scripts/serve_stage5.py --port 8765
```

首次依赖安装需要网络或已准备的包缓存。数据已经准备时先执行 `--verify`，不要覆盖半成品或修改冻结清单。资产缺失或哈希不符时，先保留错误并核对资源来源，不通过改清单绕过检查。

浏览器打开 <http://127.0.0.1:8765/>。终端保持运行，按 Ctrl+C 停止服务。端口被占用时可通过 `--port` 选择空闲端口，不结束其他项目的进程。正式本地模型推理不需要 API 密钥、SSH、GPU、重新训练或另行下载 BERT 基础模型。

## 页面操作

1. **实时抽取**：输入一段文本，选择 D0、N0 或 N1 并运行。点击实体查看原文位置及类别；没有参考标注的新文本不显示准确率。
2. **方法对比**：使用同一文本运行所选路线，查看完整结果、共同项与分歧。失败、未检出和未运行分别显示。运行中改变 API 配置会停止尚未发送的路线，已发送请求的真实返回结果仍保留。
3. **错误分析**：查看 F01—F05 的参考、历史预测和独立诊断结果。页面内容是对应版本的已保存案例，不应表述为本次现场推理。
4. **实验结果**：查看共同500、完整5000、多种子、学习率／RoPE和阈值结果。两张 SVG 随源码提供，无需运行绘图脚本。
5. **JSON 导出**：展开或下载结果，核对原文、路线、实体区间、来源与状态。文本或方法改变后重新运行；API 导出包含实际用量和可用的参考估费，不含密钥。
6. **复现验证**：启动新的完整任务，查看阶段、进度、日志和输出目录。刷新可恢复已保存任务；取消保留部分输出。历史任务按原时间展示，本次结论以新任务输出为准。

页面可以识别操作者在本地另行放置的交付文件；源码仓库不包含报告、贡献声明表或视频，文件缺失时按实际状态显示。

## API 设置

在页面右上角打开“API 设置”，选择提供商或自定义兼容接口，填写自己的密钥和模型，保存后再运行 API 路线。需要时使用页面的模型获取功能核对可选模型；获取模型列表及发送抽取请求都会访问所选服务商。

密钥只在当前页面中使用，不写入浏览器偏好存储或导出文件；服务商、模型及自定义地址偏好可以保存。L0/L3 只有在操作者主动选择并执行时才发送。发送前应确认原文可向对应服务商提供，不输入私人病例、身份信息或其他无权外发的内容。

当前现场入口记录实际用量和参考费用，不以参考价格或旧制作期预算拦截请求。价格目录、折算汇率和估费都不是账单，以服务商实际计费为准；未知用量或费用保持未知。配置变化后的对比中断会写明状态、未运行路线及原因。

## 固定权重 CPU 复现

资源就位、依赖安装完成后，使用一个尚不存在的新输出目录：

```sh
uv run --locked python scripts/teacher_reproduce.py --archive assets/CMeEE-V2.zip --output output/teacher-001
```

该入口准备或验证固定划分，再新运行 D0/N0/N1 各5000条，核对 [冻结期望](configs/reproduction-expected.json)。主种子为 `20261019`，严格实体 Micro F1 预期为 D0 **38.0192%**、N0 **60.2793%**、N1 **66.8942%**；精确整数和小数以配置为准。这些数值是固定模型的复现目标，不是新输入的准确率。

检查新输出中的 `summary.json` 和退出码。已有输出目录会被拒绝，再次运行时使用 `teacher-002` 等新目录。失败时保留输出及错误，不改权重、阈值或冻结期望去匹配目标。CPU 复现不从头训练，也不重跑历史付费 API 评估。

同一服务只运行一个完整复现任务，任务运行时可能拒绝其他冲突请求。异常退出后先核对原任务、进程和状态，不直接删除保护锁。
