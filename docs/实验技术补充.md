# 参数、指标与运行限制

本文说明本仓库的数据接口、配置入口和结果解释。安装、资源准备及页面操作见 [README](../README.md)。本地源码中的历史配置与统计不等于当前运行通过，使用时应区分现场结果、历史结果和待运行路线。

## 1. 实体与输入接口

实体以原文 Unicode 字符索引 `[start,end)` 表示，必须满足 `text[start:end]` 与实体文本一致。右端点不包含在实体内；不按 UTF-8 字节、JavaScript UTF-16单元、WordPiece或 API token 计算跨度。原文大小写、空格、标点和繁简字保留，不静默规范化。

九类实体为疾病 `dis`、临床表现 `sym`、药物 `dru`、医疗设备 `equ`、医疗操作／过程 `pro`、身体部位 `bod`、医学检验项目 `ite`、微生物 `mic`、科室 `dep`。不同提及位置分别保留；嵌套、交叉及同边界不同类别不压平成单层BIO。

长文按字符窗口推理，再回映原文并去重。覆盖到某段文本不代表实体一定被正确识别；字符词表中的 UNK 也不同于“训练实体词表未出现过的表面词”。不能由窗口覆盖或少量样例推断临床效果。

## 2. 配置入口

| 文件 | 用途 |
|---|---|
| [stage3.json](../configs/stage3.json) | 模型结构、历史开发训练、字符窗口及原始解码配置 |
| [stage4-frozen-protocol.json](../configs/stage4-frozen-protocol.json) | 正式实验的种子、参数、API提示和固定三样本来源 |
| [execution-parameters.json](../configs/execution-parameters.json) | 开发训练的优化器／裁剪，以及现场API默认值和模型预置 |
| [review-runtime.json](../configs/review-runtime.json) | CPU线程、推理微批量、输入长度、默认路线及修复门槛 |
| [reproduction-expected.json](../configs/reproduction-expected.json) | 正式数据哈希、固定权重及独立复现的期望计数／指标 |
| [stage5-repair-protocol.json](../configs/stage5-repair-protocol.json) | 阶段五历史修复实验协议，不替代当前运行配置 |

现有模型采用256字符窗口、160字符重叠和64维跨度头。N0字符嵌入128、双向LSTM每向128；N1为固定版本中文BERT＋GlobalPointer。正式主种子为20261019，正式RoPE开启、阈值为0。具体生效配置与权重manifest为准，不通过修改阈值、种子或期望值去追求复现通过。

当前运行配置默认CPU4线程、推理微批量4、输入最多4000字符、默认现场路线N1。开发训练使用历史配置中的FP32、微批量4和累积8；训练入口会保存生效参数。原有检查点续跑仍按其兼容规则处理，不能随意更换优化器或冻结输入。

普通页面启动与固定权重CPU复现不需要新训练、GPU、私人费用账本或SSH。正式模型文件与数据另行取得，清单并非资产本身。

## 3. 数据划分与评分口径

历史实验从官方训练资料中形成13497条训练、1503条内部开发；官方开发资料用于固定5000条留出评估，共同500是其中固定子集，不是另一份独立测试集。开发资料用于选参，最终留出不得回流调参、选提示或挑种子。官方隐藏测试没有本项目可用于报告成绩的金标。

- **严格实体指标**：每篇文段按 `(start,end,type)` 去重，边界和类别完全一致才计TP；跨文段累计TP、预测数和参考数，再计算Micro P/R/F1。空分母固定记0。
- **字符类型指标**：按 `(文段,字符位置,类别)` 集合计数，同一位置可有多类，同类重叠覆盖不重复计数。该指标不是严格实体分数，也不是计费token数。
- **结构及分组**：类别、实体长度、文段长度、嵌套、交叉、同跨度异类和未登录表面词按各自条件筛选；结构分组可能交叠，不直接相加。严格嵌套要求不同边界的实体区间包含关系；同边界异类单列。
- **宽松匹配**：同类且正区间重叠后做最大一对一匹配，仅作诊断，不替代严格主指标。
- **输出状态**：合法空实体集合仍是有效输出；格式非法、位置非法、未发送、未运行和传输失败分别保留。有不可用输出时，API完整集合主指标保持N/A；有效子集成绩不冒充全量结果。

给定TP、预测数P和参考数G，精确率为TP/P，召回率为TP/G，F1为两者调和平均。界面没有参考标注的新输入不计算准确率；单个样例的效果也不能替代固定集合评估。

## 4. 时延、不确定性与用量

时延需说明是否包含模型加载、预热、排队、批处理或完整网络响应。逐条秒数的均值是指定范围的算术平均；P95对排序结果在 `(n-1)×0.95` 处线性插值。扫描多个阈值时共用的前向总时长，不应当作每个阈值的单次响应时延。

三个训练种子的均值按三个F1计算，样本标准差分母为 `n-1`。同机重复推理测时不是重复训练。历史共同500区间使用相同文段索引做2000次配对bootstrap、种子20261019、2.5%与97.5%线性分位数；它不包含训练种子方差、未做多重校正，不证明跨领域或临床泛化。

API输入和输出token取实际服务响应usage。提示、训练示例及当前原文计入输入，生成JSON等内容计入输出。参考估费公式为：

```text
(input_tokens × 输入单价 + output_tokens × 输出单价) / 1,000,000
```

单价单位为人民币／百万token。目录价格或汇率是参考值，不是平台实际扣费；缺失usage或未知费用不填0。当前现场入口不读取制作期账本来拦截请求，历史冻结评估的预算／预留约束仍属于其原协议，二者不混用。

## 5. 现场API与JSON导出

现场API参数由生效执行配置和页面设置共同确定。当前默认温度0、最大输出4096 token、非流式且关闭思考；服务商与模型的实际兼容能力按入口校验。自定义接口的JSON模式可以按实际服务能力设置，不修改冻结历史提示来适配现场操作。

正式历史L0/L3使用冻结协议中的系统提示与 `text/type/occurrence` 精确出现序号映射；L3的固定三条训练样本来自 `api.example_ids`，不从最终留出选例。完整提示保存在协议中，不在本文另复制一份可能漂移的模板。

方法对比在启动时固定API配置。配置改变后不再启动后续路线，已经发送的请求保留其真实返回结果。重复操作、失败和中断不会被静默填成正常空实体；导出保留完成／中断状态、未运行路线、原因以及提供商／模型信息，不含密钥。

API密钥不写入浏览器偏好存储。程序保留配置与用量记录时排除密钥；调用者仍需确认外发原文符合数据许可及隐私要求。

## 6. 页面资源与复现任务

`ui/project-data.json` 保存已生成的实验摘要及其历史来源；`ui/demo-cases.json` 保存五个已审阅案例。两张展示SVG位于 `report-source/figures/`。这些静态展示资源随源码提供，不能当作操作者刚刚运行的新结果。

复现入口必须使用不存在的新输出目录。程序不覆盖已有预测；失败、取消或中断后保留现场。同一服务中的完整任务互斥，刷新恢复原任务状态，不重新启动一份同名任务。历史Windows与Mac通过记录只覆盖各自确切源码和环境，新版本结果以实际新输出为准。

## 7. 历史工具的使用限制

仓库保留历史训练、恢复、评估及文档生成源码，用于核对实现。调用前必须具备对应输入和适用执行条件；仅导入某些历史脚本就可能读取文件、创建记录或启动等待／子进程，不能通过导入来做静态语法检查。

| 工具 | 所需材料与可能写入 |
|---|---|
| `build_teacher_view.py` | 读取历史实验、案例与制作区汇总，生成页面数据；普通启动不需要运行它 |
| `make_supplement_figures.py` | 需要另备Matplotlib、macOS宋体及历史阈值结果，会写图表；可选外部排版核查工具通过参数提供，默认有内置检查；未扩展为跨平台通用绘图入口 |
| `finalize_stage3_docs.py`、`write_stage2_report.py`、`write_stage3_report.py` | 读取历史材料并写文档／配置，不属于普通运行步骤 |
| `write_stage4_report.py`、`write_stage4_recovery_notes.py` | 从对应历史记录生成阶段快照，不代表当前项目进度或新的真人工作记录 |
| `review_evidence.py`、历史API／控制器 | 依赖独立数据、预测、账本、源快照、服务器或资源条件；可能产生新处理或外部调用，不能直接重放旧授权 |

数据、权重、历史日志、完整预测、费用账本和制作期证据不随源码仓库提供。缺少材料时如实记录缺项，不伪造输入或用量，不修改受保护的历史结果补齐流程。
