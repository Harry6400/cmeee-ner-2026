# 报告引用日志核查说明

本包收录报告附录二中训练与独立核查所引用的原始控制台日志，供课程审阅。日志从正式主库当前工作树按原相对路径逐字节复制；主库代码快照 HEAD：6d7155b81a2f48a435d294ebc1c15ec6ab15ed80。这些源日志位于主库忽略的 evidence/ 目录，未作为主库 Git 历史的一部分。

## 内容范围

- 10 组 N1 运行记录：阶段三 4 组、阶段四新种子 2 组、阶段六补充 4 组。
- 阶段三 N1-rope-off 的 2 段续跑记录，连同原分段日志保留其完整状态变化。
- 固定权重 CPU 5000 条复现日志，以及 10 组／20 份开发预测独立重算的单行汇总。
- 报告位置对应附录二 C.1.1 的训练日志与 C.1.2 的复现、重算日志。

文件均保留源文件内容与相对路径。完整复现日志包含原运行时的 macOS 临时目录路径；该路径未改写，以保留原始记录。日志内容审阅未发现语料原文、实体标注、预测、密钥、账号或 API 请求／响应。运行记录只用于复核既有开发结果；本次没有重新训练、评估或调用 API。

项目数据许可记录见主库 docs/DATA_LICENSE.md。本包不包含数据集、数据样例、模型权重、检查点或报告成品，不扩展原数据许可范围。

## 校验

在解压后的仓库根目录运行：

shasum -a 256 -c evidence/报告引用日志清单.sha256

清单包含 14 个日志文件及本说明的 SHA-256。压缩包还包含该清单。
